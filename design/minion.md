# 使魔卡牌

## 说明

- 文件名和卡牌主索引使用英文 `cardId`，正文说明使用中文。
- 数据源为 `src/data/cards/minions.ts` 及其拆分模块。
- 每一张随从都记录英文 `cardId` 与中文名，便于和代码、卡图文件、设计文档互相对照。
- `weekend_overtime` 是 `day_off` 的衍生随从，也一并列入图鉴。
- 2026-04-30 校验：当前源码中 29 张使魔均已记录，未发现遗漏。
- v1.3 起，“登场当回合可以攻击”的关键词统一写作“疾风”。

## 当前护卫体系备注

1. `guard` 是当前防守体系的核心关键词，承担保护角色与拖延对手进攻的职责。
2. `dorm_matron` 的 `menace` 会压低敌方随从的基础威胁值，用于影响势能结算。
3. `iron_rice_bowl` 的 `magicRes` 只阻止敌方指定型魔法，不阻止非指定群体伤害。
4. `three_phase_plug` 依赖站位顺序给相邻随从添加护卫，通常需要提前规划场上排列。

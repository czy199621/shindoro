# 《神どろ》近期更新内容汇总

本文档汇总当前讨论中新增或调整的设计内容，适合作为后续同步给 Codex、规则文档或设计文档的补充材料。

# 1. 卡组构筑与保存功能

## 1.1 新增功能目标

新增完整的卡组构筑与保存系统，使玩家可以：

- 查看全部可构筑卡牌。
- 为不同角色构筑主卡组。
- 保存多个自定义卡组。
- 编辑、复制、删除、重命名卡组。
- 从默认预组创建新卡组。
- 在开局前选择已保存的合法卡组。
- 对卡组合法性进行校验。

---

## 1.2 卡组规则

```md
主卡组固定 50 张。
同名卡最多 3 张。
公共备牌终结者不能进入主卡组。
衍生卡不能进入主卡组。
【硬币】不能进入主卡组，只能通过天赋【战术硬币】获得。
【大魔力宝石】已删除，不能进入构筑列表。
```

---

## 1.3 保存数据结构建议

```ts
interface SavedDeck {
  id: string;
  name: string;
  characterId: string;
  mainDeck: string[];
  createdAt: number;
  updatedAt: number;
}

interface SavedDeckCollection {
  version: 1;
  decks: SavedDeck[];
}
```

第一阶段建议使用 `localStorage` 保存：

```ts
const DECK_STORAGE_KEY = "shindoro.savedDecks.v1";
```

---

## 1.4 卡组合法性校验

需要校验：

- 主卡组是否正好 50 张。
- 同名卡是否超过 3 张。
- cardId 是否存在。
- 是否误加入公共备牌终结者。
- 是否误加入衍生卡。
- 是否误加入【硬币】。
- 是否误加入已删除的【大魔力宝石】。

```ts
interface DeckValidationResult {
  valid: boolean;
  errors: string[];
  warnings: string[];
  cardCount: number;
  duplicateCounts: Record<string, number>;
}
```

## 1.6 开局前选择卡组

开局流程建议改为：

```md
选择角色 → 选择卡组 → 选择天赋 → 开始对局
```

如果角色没有自定义卡组，显示：

```md
该角色还没有自定义卡组。
你可以使用默认预组，或前往卡组构筑器创建卡组。
```

如果卡组不合法，不能开始对局，并显示原因。

# 2. 墓地系统与衍生卡规则补充

## 2.1 墓地系统

新增公开区域：

```md
墓地：每名玩家拥有一个公开区域，用于放置本局中已经被使用、破坏、弃置、磨掉的实体卡。
```

进入墓地的情况：

| 来源 | 处理 |
|---|---|
| 使魔被破坏 | 进入其拥有者墓地 |
| 魔法结算完毕 | 进入其拥有者墓地 |
| 陷阱触发并结算完毕 | 进入其拥有者墓地 |
| 持续魔法被破坏 | 进入其拥有者墓地 |
| 手牌被弃置 | 进入其拥有者墓地 |
| 卡组被磨牌 | 从牌库顶进入其拥有者墓地 |

---

## 2.2 衍生卡规则

```md
衍生卡不属于主卡组构筑。
衍生卡不计入 50 张主卡组限制。
衍生卡不受同名卡最多 3 张限制。
衍生卡可以被置于牌库顶、加入手牌、召唤到场上或进入墓地，具体取决于卡牌效果。
衍生卡进入墓地后可以参与墓地数量统计。
衍生卡不能被复活、回收、复制或加入主卡组，除非效果明确指定。
```

# 3. 防 Mill 衍生卡体系

## 3.1 设计目的

新增一类低费亡语使魔，用于对抗寒尘、卡奥斯和其他磨牌流。

核心设计：

```md
低费使魔死亡后，将额外生成的衍生卡置于你的牌库顶。
这些卡可以增加牌库厚度，延缓疲劳与 mill。
```

注意：

- 不是直接洗回原卡。
- 不是直接检索。
- 不是完全克死磨牌。
- 通过“放到牌库顶”形成可预期的防御和代价。

---

## 3.2 衍生卡：备份碎片

```md
### 备份碎片
1费 魔法 / 衍生

抽 1 张牌。
将此卡移出游戏。
```

设计用途：

- 增加牌库厚度。
- 抽到后可以花 1 费换掉。
- 不会无成本赚资源。

---

## 3.3 衍生卡：缓存小猫

```md
### 缓存小猫
1费 使魔 / 衍生

亡语：抽 1 张牌。
```

设计用途：

- 作为较强的防 mill 衍生使魔。
- 能站场，也能死亡后补资源。

# 4. 三叠链使魔体系

## 4.1 设计目的

三叠链是一种“递归成长使魔”体系。

```md
第一阶段使魔死亡后，将第二阶段衍生使魔置于你的牌库顶。
第二阶段死亡后，将第三阶段衍生使魔置于你的牌库顶。
第三阶段是链条终点，提供较大身材或额外收益。
```

优点：

- 防 mill。
- 形成延迟资源。
- 增加墓地触发次数。
- 不会立刻赚场面，因为需要死亡、抽到、再支付费用。

---

## 4.2 三叠链通用规则

```md
三叠链：第一阶段使魔可以编入主卡组；第二、第三阶段为衍生使魔，不能编入主卡组。
当上一阶段死亡时，将下一阶段置于你的牌库顶。
这些衍生使魔不计入 50 张主卡组限制，也不受同名卡 3 张限制。
若被磨掉，则正常进入墓地。
```

## 4.6 其他可选三叠链方向

后续可追加，但不建议第一批全部实装。

### 防火墙系列

偏护卫防守链，容易加强寒尘，需谨慎。

```md
小型防火墙 → 中继防火墙 → 终端防火墙
```

### 突击体系列

偏疾风攻击链，适合钱陈飞扬和 ggy，但可能增加斩杀压力。

```md
试作突击体 → 量产突击体 → 终式突击体
```

### 文献系列

偏抽牌与手牌过滤，适合资源控制，但容易改变资源平衡。

```md
破页书记 → 归档书记 → 禁书管理员
```

### 审计系列

偏陷阱与反制联动，适合 ggy、泉亚猫，需要墓地规则稳定后再上。

```md
初级审计员 → 中级审计员 → 终端审计官
```

# 5. 污染 / 垃圾卡体系

## 5.1 设计目的

新增一类亡语使魔，用于向对手牌库顶或手牌中塞入低质量衍生卡。

核心设计：

```md
亡语：将指定垃圾衍生卡置于对手牌库顶。
```

定位：

- 降低对手抽牌质量。
- 卡住对手手牌。
- 拖慢对手费用节奏。
- 和手牌破坏、墓地、神抽形成互动。

注意：污染不是 mill。污染会增加对手牌库厚度，因此不应直接视为寒尘加强。

---

## 5.2 污染规则

```md
部分卡牌会将“垃圾衍生卡”置于对手牌库顶或加入对手手牌。

垃圾衍生卡不属于任何玩家的主卡组构筑。
垃圾衍生卡不计入 50 张主卡组限制，也不受同名卡最多 3 张限制。
垃圾衍生卡从手牌、牌库、场上或墓地离开后，若无特殊说明，结算后移出游戏。
若多张垃圾衍生卡同时置于牌库顶，由造成该效果的玩家决定它们在牌库顶的顺序。
```

## 5.10 污染体系平衡注意

避免设计：

```md

垃圾卡费用过高且无法处理。
```

污染体系可能比 mill 更影响体感，因此第一批需要保守实装。

# 6. 观星系统与神抽独占原则

## 6.1 设计原则

《神どろ》的核心特色是“神抽”。

因此：

```md
除【神抽槽】系统外，不允许普通卡牌拥有从卡组直接检索指定卡牌的效果。
```

普通卡牌可以查看和调整牌库顶，但不能从整副牌库中直接找牌。

---

## 6.2 新增关键词：观星

```md
## 观星 X

查看你牌库顶 X 张牌，可以任意调整它们的顺序，然后放回牌库顶。

观星不会抽牌，不会检索，不会把牌加入手牌。
```

---

## 6.3 可选关键词：扰星

```md
## 扰星 X

查看对手牌库顶 X 张牌，可以任意调整它们的顺序，然后放回牌库顶。
```

---

## 6.4 允许的效果

```md
观星3：查看你牌库顶3张牌，任意调整顺序。
观星5：查看你牌库顶5张牌，任意调整顺序。
查看你牌库顶2张，将其中任意数量置于牌库底，其余按任意顺序放回牌库顶。
查看你牌库顶3张，将其中1张置于墓地，其余按任意顺序放回牌库顶。
查看对手牌库顶2张，任意调整顺序。
```

---

## 6.5 禁止的效果

```md
从你的卡组中选择一张牌加入手牌。
从你的卡组中选择一张使魔置于牌库顶。
从你的卡组中选择一张魔法牌置于手牌。
从你的卡组中检索一张费用为 X 的牌。
从你的卡组中检索一张带有指定关键词的牌。
从墓地中自由选择任意牌并在本回合使用。
```

---

## 6.6 神抽独占原则正式文本

```md
# 神抽独占原则

《神どろ》的核心特色是“神抽”。
因此，直接从卡组中选择指定卡牌的能力，只允许由【神抽槽】系统提供。

普通卡牌不得拥有“从卡组检索指定卡牌”的效果。
普通卡牌可以拥有【观星】类效果，即查看并调整牌库顶若干张牌的顺序，但不得直接从整副牌库中搜索卡牌。

允许：
- 观星
- 调整顶牌顺序
- 将顶牌置底
- 将顶牌送入墓地
- 查看对手顶牌并调整

禁止：
- 从卡组找牌
- 从卡组按类型找牌
- 从卡组按费用找牌
- 从卡组按关键词找牌
- 从墓地自由使用大量牌
- 任何会替代神抽定位的索引式检索
```

# 8. 当前建议的第一批实装内容

## 8.1 第一批推荐实装

```md
1. 卡组构筑与保存功能
2. 墓地系统基础规则
3. 衍生卡进入牌库顶与进入墓地的规则
4. 防 mill 的备份碎片体系
5. 三叠链中的备份体系列、回溯体系列、墓灯系列
6. 污染体系第一批垃圾衍生卡与污染使魔
7. 观星关键词与神抽独占原则
```

---

## 8.2 暂缓实装

```md
1. 防火墙三叠链
   - 容易让寒尘重新变强。

2. 疾风突击三叠链
   - 可能提高钱陈飞扬和 ggy 的斩杀压力。

3. 文献抽牌三叠链
   - 容易改变资源平衡。

4. 审计陷阱三叠链
   - 会反复利用陷阱，需要墓地规则稳定后再考虑。

5. 大量直接塞手牌的污染卡
   - 体感可能过差，先以置于牌库顶为主。
```

# 9. 对现有角色的影响预测

| 角色原型 | 影响 |
|---|---|
| 跳脸爆发型 | 观星可以提高斩杀规划，但不能直接找牌。污染体系对其不太适合。 |
| 逆风神抽型 | 三叠链和备份体系较适合，能拖到神抽与公共备牌。 |
| 场面滚雪球型 | 可少量使用三叠链，但不应过度偏慢。 |
| 硬解中速型 | 回溯体系列非常适合，能惩罚高价值随从交换。 |
| 反击疾风型 | 污染和观星都可少量使用，但更适合保持进攻节奏。 |
| 磨牌控制型 | 需要限制防火墙链和大量防 mill 卡，避免寒尘重新过强。 |
| 手牌破坏控制型 | 污染体系非常适合，但要防止对手完全不能玩游戏。 |

# 10. 设计注意事项

## 10.1 防 Mill 不能完全克死 Mill

防 mill 卡应该延缓疲劳与磨牌，不应该让磨牌流完全失去胜利方式。

## 10.2 污染不能过度影响体感

污染卡比磨牌更容易让对手觉得“不能玩游戏”。

因此：

- 低费污染只给弱垃圾。
- 强垃圾只由中费以上卡生成。
- 尽量先置于牌库顶，而不是直接加入手牌。

## 10.3 观星不能变成变相检索

观星只能操作牌库顶，不能直接从卡组找牌。

```md
直接找牌 = 神抽系统独占。
```

## 10.4 衍生链不能过度加强寒尘

寒尘已经有磨牌、护卫和回复方向。所有护卫型、防 mill 型、延迟资源型衍生链都要重点测试寒尘是否过强。

# 11. 下一步建议

建议按以下顺序推进：

```md
第一步：实现墓地与衍生卡规则。
第二步：实现卡组构筑与保存。
第三步：加入少量防 mill 卡，测试寒尘与卡奥斯。
第四步：加入三叠链第一批，测试中慢速资源环境。
第五步：加入污染体系第一批，测试对局体感。
第六步：加入观星关键词，确认不会破坏神抽独占性。
第七步：重做各角色预组卡组。
```

## 1. 规则事实源关系

初版中，`game_rule.md` 是当前规则事实源，基础规则包括：

- 初始生命值 20 点。
- 主卡组固定 50 张。
- 同名卡最多 3 张。
- 备牌库独立于主卡组。
- 回合流程为：回合开始阶段、摸牌阶段、主要阶段、战斗阶段、回合结束阶段。
- 回合结束时结算总势能差，并分配跳脸槽或神抽槽。
- 跳脸槽是优势方资源。
- 神抽槽是劣势方资源。
- 10 点触发角色专属大招。
- 13 点触发 Overkill。

v1.3 修改应优先同步到：

- `game_rule.md`
- `game_design.md`
- `角色图鉴.md`
- `minion.md`
- `spells.md`
- `traps.md`
- 后续新增的墓地系统文档或规则补丁文档

# 2. 术语统一

## 2.1 “冲锋”统一改为“疾风”

### 修改前

新版使魔中文名表中，部分 `rush` 机制写作“冲锋”，例如：

- 余烬狼：冲锋。
- 暴风枪骑：冲锋。

但公共备牌终结者“绝影刺客·瞬”写作“疾风”。

### 修改后

所有表示“登场当回合可以攻击”的关键词，统一写作：

> **疾风**

### 需要替换

| cardId | 中文名 | 原写法 | 修改后 |
|---|---|---|---|
| `ember_wolf` | 余烬狼 | 冲锋 | 疾风 |
| `storm_lancer` | 暴风枪骑 | 冲锋 | 疾风 |
| `shun_shadow_assassin` | 绝影刺客·瞬 | 疾风 | 疾风 |

### 关键词定义

```md
疾风：该使魔登场的当回合即可攻击。
```

# 3. 硬币系统重做

## 3.1 删除【大魔力宝石】

### 修改前

```md
大魔力宝石
0费魔法。
第5回合后才能使用。
本回合获得2点当前可用费用。
第7回合后改为获得3点当前可用费用。
```

### 修改后

> **删除【大魔力宝石】。**

不再作为普通魔法进入主卡组。

删除理由：

- 0费中后期跳费卡容易和高费大魔法、公共备牌终结者形成过强爆发。
- 跳费资源应从“卡组随机抽到的爆点”改为“赛前购买的天赋资源”。
- 删除后，费用爆发更可预期，也更容易平衡。

---

## 3.2 新增核心天赋：【战术硬币】

```md
## 战术硬币

天赋消耗：先手 4 点 / 后手 1 点
机制定位：动态跳费 / 节奏爆发

效果：
游戏开始时，将一张 0 费魔法卡【硬币】置入你的手牌。
```

### 设计意图

- 先手 4 点：限制先手无脑拿硬币滚雪球。
- 后手 1 点：保留后手补节奏和反击能力。
- 硬币变成明确的赛前投资，而不是默认系统补偿。
- 删除大魔力宝石后，硬币成为唯一主要一次性跳费资源。

---

## 3.3 【硬币】卡牌效果重做

### 修改前

```md
硬币
0费魔法。
本回合获得1点法力。
```

### 修改后

```md
硬币
0费魔法。

根据当前回合数，本回合获得临时费用：

- 第 1～3 回合：获得 1 点临时费用。
- 第 4～6 回合：获得 2 点临时费用。
- 第 7～8 回合：获得 3 点临时费用。
- 第 9 回合开始时，若此卡仍在你的手牌中，将其移出游戏。
```

### 建议追加限制

```md
此卡不能被复制，不能从墓地回收，不能通过其他效果额外生成。
每名玩家每局最多因【战术硬币】获得 1 张【硬币】。
```

### 设计意图

| 阶段 | 硬币收益 | 设计作用 |
|---|---:|---|
| 1～3回合 | +1 | 后手补节奏，先手付高价才能使用 |
| 4～6回合 | +2 | 中盘抢关键节奏点 |
| 7～8回合 | +3 | 支持高费魔法、公共备牌终结者或终局爆发 |
| 第9回合后 | 移出游戏 | 防止长期囤积成为超后期核弹 |

# 5. 陷阱修改

## 5.1 镜像之墙加强

### 修改前

```md
镜像之墙
2费陷阱。
敌方施放法术后，对敌方角色造成 3 点伤害。
```

### 修改后

```md
镜像之墙
2费陷阱。
敌方施放法术后，对敌方角色造成 4 点伤害。
```

### 修改理由

2费陷阱具有盖伏成本、触发条件和后场占位。3伤偏温和，4伤更能形成有效反制。

### 注意事项

4点伤害会和某些“受到超过3点伤害”类角色被动产生互动，这属于可接受的策略点。

---

## 5.2 伏击印记加强

### 修改前

```md
伏击印记
2费陷阱。
敌方召唤使魔后，对该使魔造成 2 点伤害。
```

### 修改后

```md
伏击印记
2费陷阱。
敌方召唤使魔后，对该使魔造成 3 点伤害。
```

### 修改理由

2点伤害对当前 2～4 费使魔经常不足以形成有效惩罚。3点伤害更能压制低血随从与进场节奏。

---

## 5.3 魔力干涸削弱

### 修改前

```md
魔力干涸
2费陷阱。
当对手当前可用费用正好为 5 点时触发，使其当前可用费用 -3。
```

### 修改后

```md
魔力干涸
2费陷阱。
当对手当前可用费用正好为 5 点时触发，使其当前可用费用 -2。
```

### 修改理由

-3 过于容易导致对手关键回合接近跳过。-2 更符合自身 2 费成本，也仍然能打断中期爆发。

# 6. 公共备牌终结者修改

## 6.1 不采用统一“本回合不能攻击”规则

### 废弃方案

```md
通过 13 点神抽打出的公共备牌终结者，本回合不能攻击。
```

### 当前修正

不采用公共规则一刀切。

理由：

- 绝影刺客·瞬的定位就是疾风斩杀，不应被限制。
- 时空篡夺者·乌洛波洛斯需要保留战斗价值和额外回合定位。
- 限制应写进部分大号终结者的卡面，而不是限制所有备牌终结者。

---

## 6.2 新增负面词条候选：【重压】

```md
重压：此卡进场后，本回合你跳过战斗阶段。
```

也可以不命名关键词，直接写作：

```md
进场后，本回合你跳过战斗阶段。
```

| 卡牌 | 是否添加“重压” |
|---|---|
| 虚数之影·卡奥斯 | 添加 |
| 神罚代行者·米迦勒 | 添加 |
| 绝对裁决者·尤斯蒂娅 | 添加 |
| 绝影刺客·瞬 | 不添加 |
| 时空篡夺者·乌洛波洛斯 | 不添加 |

### 设计理由

卡奥斯、米迦勒、尤斯蒂娅拥有极强进场效果，如果进场后还能继续进行战斗阶段，会让 13 点神抽备牌过于全面。

# 7. 角色技能修改

## 7.1 寒尘削弱

### 修改前

```md
寒尘

被动：摸牌回春
进入自己的抓牌阶段时，先回复 1 点生命。

跳脸10点：十连磨牌

Overkill13点：反伤磨尽
先磨对手 10 张牌，并在本回合把你受到的伤害转化为额外磨牌。
```


# 8. 新增墓地系统

为了后续大量墓地主题卡牌，需要正式加入墓地区域。

## 8.1 新增区域：墓地

```md
墓地：每名玩家拥有一个公开区域，用于放置本局中已经被使用、破坏、弃置、磨掉的实体卡。
```

---

## 8.2 进入墓地的情况

| 来源 | 处理 |
|---|---|
| 使魔被破坏 | 进入其拥有者墓地 |
| 魔法结算完毕 | 进入其拥有者墓地 |
| 陷阱触发并结算完毕 | 进入其拥有者墓地 |
| 持续魔法被破坏 | 进入其拥有者墓地 |
| 手牌被弃置 | 进入其拥有者墓地 |
| 卡组被磨牌 | 从牌库顶进入其拥有者墓地 |
| 衍生卡离场 | 建议结算后移出游戏，不常驻墓地 |

---

## 8.3 墓地记录需求

数字实现建议为墓地记录以下信息：

```ts
interface GraveyardEntry {
  cardId: string;
  ownerId: PlayerId;
  fromZone: "battlefield" | "hand" | "deck" | "backrow" | "stack";
  reason: "destroyed" | "used" | "discarded" | "milled" | "sacrificed";
  turn: number;
  wasCombatDestroyed?: boolean;
  combatKillerInstanceId?: string;
}
```

重点字段：

```ts
wasCombatDestroyed?: boolean;
combatKillerInstanceId?: string;
```

用于支持“被敌方使魔通过战斗破坏时，将破坏者也拖下水”的亡语。

# 9. 新增亡语机制方向

## 9.1 新机制描述

新增一种亡语型使魔机制：

```md
亡语：若此使魔是被敌方使魔通过战斗破坏，破坏造成这次战斗破坏的敌方使魔。
```

也就是：

> 这个使魔死了时，如果是被敌方使魔通过战斗破坏的，就把那个敌方使魔也拉下水。

---
